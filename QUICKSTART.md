# Quick Start Guide

## Installation

1. **Install dependencies:**
```bash
cd next-shadcn-dashboard-starter
bun install
# or
npm install
```

2. **Start the development server:**
```bash
bun dev
# or
npm run dev
```

3. **Open your browser:**
Navigate to http://localhost:3000

## First Steps

1. **View Dashboard**: Go to `/dashboard/overview` to see statistics
2. **Add a Doctor**: Go to `/dashboard/doctors/new`
3. **Add a Bed**: Go to `/dashboard/beds/new`
4. **Add a Patient**: Go to `/dashboard/patients/new`

## Default Data

The system automatically creates:
- 3 sample doctors
- 20 beds (various types)
- Empty patient list
